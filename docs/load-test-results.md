## 7. 关键结论

1. **模型不是瓶颈**：DeepSeek-flash 官方并发上限 2500，远超本机能压的量。
2. **真瓶颈是物理 16 核**：100 用户时 32 个沙箱 VM 把 16 物理核榨干 → 45 次沙箱创建失败。
3. **吞吐饱和点**：50→100 并发只涨 5%（276→290/min），但 P50 翻倍（8.1s→21.7s）。
4. **舒适容量**：50 并发（276/min，0 失败）；对应 ~7500 注册用户（混合强度分布）。
